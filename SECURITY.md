# Security Policy

## Supported Versions

We release security updates for the latest minor version of **KeyHarbour kh**.

| Version | Supported          |
| ------- | ------------------ |
| 1.15.x  | :white_check_mark: |
| < 1.15  | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in KeyHarbourCE, please report it privately using one of the following methods:

1. **GitHub Private Vulnerability Reporting** (Recommended): Go to the **Security** tab of this repository and click **"Report a vulnerability"**.
2. **Email**: Send an encrypted or detailed report to **infra.crew@keyharbour.ca**.

### What to include in your report
- Type of issue (e.g., SQL injection, XSS, authentication bypass, cryptographic flaw)
- Full paths of source file(s) related to the manifestation of the issue
- Step-by-step instructions to reproduce the issue (or a Proof of Concept)
- Potential impact of the issue

### Response Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide a detailed assessment and estimated fix timeline within **5 business days**.
- Once patched, we will publicly credit your discovery (unless you prefer to remain anonymous).
